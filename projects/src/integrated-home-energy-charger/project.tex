A 50~kW bidirectional home fast charger that takes 120~Vac split-phase in and
delivers 250--400~Vdc to a vehicle, with PV and storage folded into the same
box rather than bolted on beside it.

\section{Architecture}

\begin{itemize}
  \item Interleaved PFC front end on the split-phase input.
  \item Active power decoupling, which removes the bulk energy-storage
        capacitance a single-phase system would otherwise need.
  \item Isolated DC--DC stage built on SiC MOSFETs.
  \item Bidirectional operation, so the vehicle can support the house as well
        as draw from it.
  \item Automatic integration of PV and storage alongside EV charging.
\end{itemize}

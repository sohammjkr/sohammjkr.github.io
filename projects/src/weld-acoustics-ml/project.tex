A system that classifies weld quality from the sound of the weld itself.
Welding produces a characteristic acoustic signature; the question was whether
that signature carries enough information to flag a bad weld as it happens,
without instrumenting the workpiece.

\section{Pipeline}

\begin{itemize}
  \item MFCC feature extraction from raw acoustic recordings, in Python with
        Librosa.
  \item SVM classifiers trained on Caterpillar welding lab datasets.
  \item Python GUI giving the operator immediate feedback.
  \item Arduino and LED prototype alert stack for a shop-floor signal.
\end{itemize}

\img{/assets/weldacoust.png}{The implementation stack, from live audio
through to a good, bad or unsure call.}

\section{Result}

75--84\% test accuracy on the Caterpillar welding lab datasets.

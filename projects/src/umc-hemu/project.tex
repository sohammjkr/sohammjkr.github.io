A multiport bidirectional high-frequency-link split-phase DC/DC/AC converter:
one high-frequency isolation stage serving several ports, so PV, storage and a
split-phase AC output share the same magnetics instead of each needing their
own converter.

\section{Approach}

\begin{itemize}
  \item Tri-port architecture around a single high-frequency link.
  \item Bidirectional DC/AC conversion, single-stage.
  \item Ultra-low leakage inductance transformer design.
  \item Sigma-delta modulation for AC synthesis.
  \item Split-phase output, matching North American residential service.
\end{itemize}
